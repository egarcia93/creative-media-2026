EXAMPLE

EL FESTIVAL INVERNAL

THE EVENT

A music festival that only happens on winter nights

SIGNALS

Heat waves, summer festivals cancelled

WHAT CHANGED

Summer is for staying inside, winter is for going out

WHO RUNS IT

A cooperative of small venues, with city money

WHO IS IN

Residents with a culture pass. Tourists pay double

WHAT SURVIVES

Dancing in the street, together

WHOSE EYES

The sound technician of the main stage

THE LOOK

Cold blue, breath in the air, flashlights

PROBABLE

An energy company buys the festival. Shorter, more expensive

PLAUSIBLE

A blackout. The festival moves into the metro stations

PREFERABLE · CHOSEN

Free stages in every neighborhood, run by local associations

CSS RECIPES

Colors and links

tw-story {
  background: #0e0d14;
  color: #e6e6ff;
}
tw-link { color: #ff2bd6; }

An image behind everything

tw-story {
  background: url("URL") center / cover;
}

A Google font, first line of the stylesheet

@import url("https://fonts.googleapis.com/
  css2?family=Space+Mono");
tw-story { font-family: "Space Mono"; }

A box to read on

tw-passage {
  background: rgba(0,0,0,0.6);
  padding: 2em;
}
